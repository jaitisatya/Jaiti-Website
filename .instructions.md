## 1️⃣ SEO & Branding Rules

### Meta Tags & Open Graph
- ✅ Every new HTML page MUST include:
  - `<meta charset="UTF-8">`
  - `<meta name="viewport" content="width=device-width, initial-scale=1.0">`
  - `<meta name="description">` with keywords
  - `<meta name="keywords">`
  - `<meta name="author" content="Jaiti Foundation">`
  - `<meta name="robots" content="index, follow">`
  - All Open Graph tags (og:title, og:description, og:image, og:url, og:type)
  - Twitter card tags

### Title & Description Standards
- **Title Format:** `Jaiti Foundation | [Page Name] | Empowering Underprivileged Children`
  - Examples:
    - `Jaiti Foundation | Home | Empowering Underprivileged Children Through Education`
    - `Jaiti Foundation | About Us | Empowering Underprivileged Children`
    - `Jaiti Foundation | Daily Drive Update | Track Teaching Progress`

- **Description Keywords (mandatory):**
  - education, free education, underprivileged children, Jaipur, NGO, moral values, civic sense, holistic development

- **Canonical Links:**
  - Every page MUST have: `<link rel="canonical" href="https://jaiti.in/[page]">`

### Image Alt Text (Mandatory)
- ✅ Every `<img>` tag MUST have descriptive alt text
- Format: `alt="[Context] at Jaiti Foundation, Jaipur"`
- Examples:
  - `alt="Children studying at Jaiti Foundation free education center"`
  - `alt="Volunteer teacher conducting class at Jaiti Foundation"`
  - `alt="Jaiti Foundation students receiving nutritious meals"`

## 2️⃣ Image Optimization Rules

### Format & Compression
- ✅ **Format:** WebP ONLY (no JPG/PNG on production)
- ✅ **Max File Size:** 100 KB per image
- ✅ **Quality:** Maintain visual quality at 80% compression
- ✅ **Lazy Loading:** `loading="lazy"` on ALL images below fold

### Image Dimensions
| Type | Dimensions | Max Size |
|------|-----------|----------|
| Hero/Background | 1920×1080 px | 150 KB |
| Program Cards | 600×400 px | 80 KB |
| Gallery Images | 1200×800 px | 120 KB |
| Thumbnails | 400×300 px | 50 KB |
| Logo | 200×200 px | 30 KB |
| Social Images | 1200×630 px | 100 KB |

### Lazy Loading Implementation
```html
<!-- Do this: -->
<img src="image.webp" alt="Description" loading="lazy">

<!-- NOT this: -->
<img src="image.webp" alt="Description">
```

## 4️⃣ Volunteer & Check-in System

### Volunteer Signup Form
- ✅ Location: `/volunteer.html`
- ✅ Required fields:
  - Full Name
  - Email
  - Phone Number (10 digits)
  - Skills (checkboxes: Teaching, Mentoring, Content, Other)
  - Availability (dropdown: Weekdays, Weekends, Both)
  - Message (text area)

- ✅ Validation:
  - Email format check
  - Phone exactly 10 digits
  - Message minimum 2 words
  - Required field indicators

### Daily Drive Update System

#### Files Created
- `daily-drive-update.html` - Main check-in form
- `login.html` - Authentication
- `dashboard.html` - View submissions (logged-in users)
- `admin-panel.html` - Admin controls

#### Access Rules
- ✅ **Signup:** Anyone can sign up with any email
- ✅ **Approval:** Only `jaitifoundation@gmail.com` (admin) can approve users
- ✅ **Access:** Only approved users can access check-in form
- ✅ **Frequency:** One submission per day (organization-wide)
- ✅ **Edit:** Users can edit submissions until midnight

#### Form Fields
1. **Date** - Auto-filled, read-only
2. **Children Taught** - Number input (required)
3. **Teachers** - Dynamic list (add/remove fields)
   - Field: Teacher name (required)
   - Minimum 1 teacher
4. **Duration** - Hours + Minutes dropdowns
5. **Photo** - Upload image (auto-compressed ≤100 KB)

#### Photo Compression Rules
- ✅ Client-side compression (JavaScript Canvas API)
- ✅ Max output: 100 KB
- ✅ Supported formats: JPG, PNG, WebP
- ✅ Show file size: "Original: 2.5 MB → Compressed: 95 KB"
- ✅ Reject if still >100 KB after compression

#### Data Storage
- ✅ Backend: Google Apps Script (free)
- ✅ Database: Google Sheets (shared with admin)
- ✅ Auto-timestamp: Date, Time, Submitter name
- ✅ Photo storage: Google Drive (linked in sheet)

#### Daily Limit Behavior
```
User submits at 5:30 PM
↓
Next attempt at 6:15 PM shows:
"Daily Drive Update already submitted at 5:30 PM
Next check-in available tomorrow at 12:00 AM"
↓
Option to view/edit previous submission
```

## 6️⃣ Consistency & Accessibility

### Footer Requirements
- ✅ Contact info (phone, email, address) repeated
- ✅ Social media links (Instagram, YouTube, Facebook, LinkedIn)
- ✅ Quick links to all pages
- ✅ Copyright notice with current year
- ✅ Donation button/QR code visible

### Design Consistency
- ✅ **Primary Color:** #3a7260 (Earthy Teal)
- ✅ **Accent Color:** #dd6c4a (Warm Coral)
- ✅ **Font Family:** Playfair Display (headings), Inter (body)
- ✅ **Border Radius:** 0.5rem (default), 1rem (cards)
- ✅ **Shadows:** Consistent shadow variables from CSS

### Accessibility Standards (WCAG 2.1)
- ✅ **Heading Structure:**
  - One `<h1>` per page
  - Sequential h2, h3, h4 (no skipping)
  - Descriptive heading text

- ✅ **Alt Text:**
  - All images must have descriptive alt text
  - Decorative images: `alt=""`
  - Functional images: describe function

- ✅ **Color Contrast:**
  - Text vs background: 4.5:1 ratio (minimum)
  - Use color + patterns (not color alone)

- ✅ **Form Labels:**
  - Every input has associated `<label>`
  - Use `for` attribute linking to input `id`

- ✅ **Keyboard Navigation:**
  - All buttons/links accessible via Tab
  - Focus visible (outline/highlight)
  - No keyboard traps

- ✅ **ARIA Labels:**
  - Buttons: `aria-label="Close menu"`
  - Icons: Meaningful labels
  - Regions: `aria-label="Navigation"`

### Mobile Responsiveness
- ✅ Breakpoints: 320px, 768px, 1200px
- ✅ Touch targets: Minimum 48×48 px
- ✅ Viewport meta tag on all pages
- ✅ Test on mobile, tablet, desktop

### Performance Rules
- ✅ Defer script loading: `<script src="script.js" defer></script>`
- ✅ Lazy load images below fold
- ✅ Throttle scroll events (100ms minimum)
- ✅ No render-blocking CSS/JS above fold

## 9️⃣ Code Quality Standards

### HTML Structure
- ✅ Valid HTML5
- ✅ Semantic tags: `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`
- ✅ Proper nesting
- ✅ No inline styles (use CSS classes)

### CSS Rules
- ✅ CSS variables for colors, spacing, shadows
- ✅ Mobile-first approach
- ✅ No hardcoded pixel values (use variables)
- ✅ Consistent spacing using `--spacing` variables

### JavaScript Best Practices
- ✅ Use `const`/`let`, avoid `var`
- ✅ Comment complex logic
- ✅ Use descriptive function names
- ✅ Error handling with try/catch
- ✅ Event delegation for dynamic elements
- ✅ Throttle/debounce scroll/resize events
